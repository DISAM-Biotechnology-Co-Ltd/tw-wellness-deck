# Taiwan Wellness Deck

`tw-wellness-deck` is a Codex skill for turning prepared product content and brand references into PPTX or HTML presentations for Taiwan health, wellness, skincare, and beauty products.

## Use

In Codex, call `$tw-wellness-deck` and provide the product content, any DM or brand assets, the audience, and the desired output format. If no slide count is given, the skill uses 8–10 slides including the cover.

See [使用手冊.md](使用手冊.md) for a short guide and example prompt.

## Package contents

- `SKILL.md`: skill instructions
- `agents/openai.yaml`: Codex UI metadata
- `references/`: visual, compliance, production, and QA guidance
- `使用手冊.md`: user guide
